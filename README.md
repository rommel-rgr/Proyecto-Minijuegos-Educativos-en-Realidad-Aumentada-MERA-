# MERA – Minijuegos Educativos en Realidad Aumentada

Un proyecto de minijuegos educativos desarrollado en Godot, que busca combinar el aprendizaje y la tecnología a través de experiencias interactivas.

## Descargar el juego

[![Descargar MERA](https://img.shields.io/badge/Descargar-MERA-brightgreen?style=for-the-badge&logo=github)](https://github.com/rommel-rgr/Proyecto-Minijuegos-Educativos-en-Realidad-Aumentada-MERA-/releases/)

Descarga la última versión disponible del juego desde la sección de Releases.

## Información del proyecto

- **Motor:** Godot Engine
- **Plataforma:** Windows y Android
- **Tipo de proyecto:** Minijuegos educativos
- **Nombre:** MERA

## Instalación (Windows)

1. Descarga el ZIP de la plataforma correspondiente desde Releases.
2. Extrae los archivos del ZIP.
3. Ejecuta el archivo del juego.

(Nota: manten el .exe y el .pck en la misma carpeta para su correcto funcionamiento)

## Instalación (Android)

1. Descarga el APK de la plataforma correspondiente desde Releases.
2. Descarga el APK desde DOcumentos o desde un explorador de archivos.
3. Ejecuta el juego y aceptar todos los permisos.

(Nota: manten el .exe y el .pck en la misma carpeta para su correcto funcionamiento)
